上传接口的多部分解析把文件名原样拼进路径，攻击者用两个点和一个斜杠就把文件写到了目录外：部分边界必须与头部声明一致；每个部分的头部必须完整解析；文件名必须重命名且不得包含路径分隔符；部分数量与总大小必须有上限；嵌套多部分必须拒绝；批量解析中的每个请求必须各自独立。任何部分的文件名都不得带出所在目录，同一请求解析两次必须得到相同结果。
